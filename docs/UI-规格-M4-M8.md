## 二、隐藏区密码门（M4，`vault_gate_page.dart`）

- **底**：深墨绿满屏（不是 mist）。隐藏区在视觉上要和主区断开，这是刻意的。
- **结构**：居中锁图标（圆底，mint 描边）→ 标题「给隐藏区设一个密码」/「隐藏区」→ 6 圆点 → 数字键盘。
- **键盘**：`PinKeypad`，浅色键面、mint 强调；数字 1–9 三列，底行 空 / 0 / 退格。
  键面 **66×66**，列间距 **20**、行间距 **13**（`_colGap` / `_rowGap`）。
- **两种态**：首设（无 `vault.db` 时）文案讲"设一个只有你知道的密码"；已设时文案讲"输密码进隐藏区"。
- **错密码**：只震一下 + 提示"密码不对"，清空圆点，不跳转。

## 三、隐藏区主页（M4，`vault_home_page.dart`）

- 结构与主区首页同构（笔记本网格 + 隐藏条），但底色与主区区分，且**没有返回主区的入口**——退出靠系统返回 + 重新上锁。
- 网格沿用首页同一套宽度规则（`home_page.dart`）：**≥840 → 4 列 / ≥600 → 3 列 / 其余 2 列**，间距 12，页边 20（≥600 时 24）。

## 四、设置页（M5，`settings_page.dart`）

- **四组卡片**，自上而下：安全与隐私 / 写作与显示 / 数据 / 关于。
- **每行**：左标题 + 右控件（开关或值 + `>`），行间 `#F0F7F4` 1px 分隔。
- **限宽**：平板 `maxWidth 600` 居中；手机满宽（左右 20 padding）。
- **行内padding**：上下各 13、左右各 14（`EdgeInsets.fromLTRB(14, 13, 14, 13)`）；标题字号 13，副标题 11。
- 开关项与实际能力必须对应：`screenshotProtect` 已接 `FLAG_SECURE`（M8）；`biometricUnlock` / `cloudBackup` 目前只存状态。

## 五、改隐藏区密码（M7，`change_vault_pin_page.dart`）

- 两步：先输旧密码 → 再输新密码。同 `PinKeypad`，深底与隐藏区门一致。
- 步骤提示写在圆点上方一行，字号 14、`ink3`。
- 走 `PRAGMA rekey` + 换盐 sidecar；失败必须回滚到旧密钥，不能让库打不开。

## 六、局域网互传（M8，`lan_transfer_page.dart`，08 屏）

- **整页限宽** 600 居中（含标题栏）。平板横屏同样限宽，内容靠上。
  `side = page.maxWidth > 640 ? (page.maxWidth - 600) / 2 : 0.0`
- **码卡**：白底圆角 13，居中。图标（广播波纹）→ 一行说明「让对面输入这个码」（字号 12）→ 6 位数字，`mint700`、**字号 30、字距 3** → 小字提示（10.5，行高 1.7）→ **本机地址小条**（`mint100` 底、字号 11）。
- **设备列表卡**：空态是「还在找…」+ 两行解释；有设备时每行是设备名 + 6 位码。
- **手动入口**：列表卡下方一行 `TextButton.icon`，「找不到？手动输入对方地址」，`mint700`。
  弹窗两个输入框（对方地址 / 对方 6 位码），解析失败与码位不对分别给中文提示。
- **「怎么用」三步**：编号圆点 `mint100` 底 + `mint700` 数字，标题 13 ink，说明 11 `ink3`。
- **页脚两句**：直连不经路由器、开始前确认对端是谁。

## 七、跨屏共性

| 项 | 规定 |
|---|---|
| 正文 | `fontSize 14` + `height 2.0` = 28 逻辑像素行盒；信纸横线同按 28 画 |
| 按钮最小触区 | 44×44 |
| 平板判定 | `maxWidth >= 720` 走平板版式 |
| 平板竖屏 | 1024×1366 为基准 |
| 平板横屏 | 1366×1024 为基准手机之外的第二个主姿态 |
