# 信封日记 · M3 信封编辑页规格（05 屏）

> 本文从 `信封日记UI/信封日记-界面稿.html` 的 05 屏（第 130–149 行 CSS、513–550 行结构）逐项反推。
> M2 的 `docs/UI-规格.md` 第 453 行只有一句摘要，不足以照抄实现，故单列本文件。
> 数值基准：设计稿手机壳 360×760。Flutter 按 1:1 逻辑像素实现，真机 390×844 宽出的 30px 由画布左右 20 的 padding 吸收，平板沿用单列、信纸限宽。

## 1 结构

```
顶栏 ed-top        高 44（含下边距 8）
画布 ed-canvas     flex:1，浅绿底，padding 14 20 0，overflow hidden
  └ 翻折 flap        绝对定位 top:0 左右:0 高 52，底部虚线
  └ 信纸 letter      白底横线本，圆角 3
底栏 ed-bar        高 54，白底，上边框 1px
```

## 2 顶栏

| 元素 | 尺寸 / 样式 |
|---|---|
| 返回箭头 | 18×18，描边 1.6，圆角端点，色 `ink` |
| 元信息 `ed-meta` | 11px，`ink3`，letter-spacing 0.04em，文案「11月16日 · 日常碎片」（日期 · 笔记本名） |
| 完成 `ed-save` | 13px，w700，`mint700`，letter-spacing 0.06em，点击保存并返回 |

水平：两端对齐，左右 padding 20，下边距 8。

## 3 画布与翻折

- 画布底色 `#DDEEE8`（**注意**：`UI-规格.md` 0.3 表建议替换为 `mist` #EDF6F3，但 mist 太浅、和白色信纸拉不开层次。此处保留原色，新增 `EnvxColors.canvas = #DDEEE8`）。
- 画布 padding：上 14、左右 20、下 0，`overflow: hidden`。
- 翻折 `flap`：绝对定位贴顶，左右通栏，高 52，垂直渐变 `#CFE5DE` → `#DDEEE8`（渐变止于 78%），底部 1px 虚线 `#C2DCD4`。
- 语义：这 52px 是信封被拆开的"上盖"，信纸从它下面开始，形成摊开感。

## 4 信纸

| 项 | 值 |
|---|---|
| 背景 | `#FFFFFF` |
| 圆角 | 3 |
| 内边距 | 上 24 / 左右 22 / 下 34 |
| 阴影 | `0 12px 26px -16px rgba(23,95,85,.55)` |
| 横线 | 周期 28，线宽 1，色 `#F3F9F6` |

### 4.1 横线对齐（铁律，最易错）

设计稿用 `repeating-linear-gradient(#fff 0 27px, #F3F9F6 27px 28px)`，CSS 背景默认从 **padding box** 左上角起算。因此：

- 横线起点 = 内容区顶部 + 0
- 第 1 条线在 y = 27（相对内容区），第 n 条在 `27 + 28*(n-1)`
- 正文本行盒 = 24 + 28*(n-1) ~ 24 + 28*n（相对信纸边框）
- 两者相减：**线正好压在每一行文字的底部 1px**

Flutter 侧必须满足三条，缺一条就会出现"文字浮在线中间"：

1. 正文 `TextStyle(fontSize: 14, height: 2.0)` → 行盒 28。
2. 横线用 `CustomPainter` 画，起点对齐**文字内容区顶部**，不是信纸边框顶部（要减去 padding-top 24）。
3. 线与文字同层，线在下、字在上；不能用 `Container` 背景图，因为 Flutter 里 `DecorationImage` 的 origin 是 border box，会整体偏 24。

标题 `h3`（21/w900/lh 1.5/margin-bottom 14）不参与本规则，它自带 1.5 行高，下方 14 留白后正文才开始。

## 5 邮票

绝对定位 right 16 / top 14，38×46，1px 虚线 `#B9D5CC`，底色 `#F6FBF9`，居中放一个 18×18 的信封线稿图标（描边 `mint500` 1.3）。纯装饰，不响应点击。

## 6 贴纸插图

| 项 | 值 |
|---|---|
| 外框宽 | 150 |
| 外边距 | `16 0 14 6`（左 6 形成略偏的贴法） |
| 白边 | `5 5 22`（下 22 是宝丽来式留白） |
| 阴影 | `0 8px 18px -10px rgba(23,95,85,.5)` |
| 旋转 | **-2.2°** |

插图是可插入的（M3 要支持），因此实现上做成 `StickerPhoto` 组件：接收 `File`/内存图，套上述白边与旋转。

## 7 底栏

高 54，白底，上边框 1px `line` 色，四图标 `space-around`，尺寸依次 22 / 22 / 22 / 24：

1. 排版（三横线 + 折角箭头）
2. 图片（相框 + 山形）→ **点击插入图片**
3. 清单（三横线 + 三个空心圆）
4. 信封（末位，描边用 `mint700`，24×24）→ 收起信封 / 回到列表

前三个 M3 只做视觉与"演示中"提示，不实现富文本排版；图片那个必须真能插入。

## 8 交互

- 进入：从笔记列表点某行 → 编辑页，传入笔记 id，标题/正文预填，正文可编辑。
- 完成：写回数据库（`updatedAt` 刷新），返回列表。
- 返回箭头：未保存时提示"放弃这次修改？"（两个动作：继续写 / 放弃）。
- 图片：从相册选图，落盘到应用目录，插入到光标位置，显示为 6 节贴纸样式。
- 平板：单列，信纸限宽 560 居中，画布底色铺满。

## 9 开封动效（M3 新增，设计稿未画）

设计稿是静态图，动效由本规格定义，保持"同一张信封三态"的语义：

- 进入编辑页：翻折 `flap` 从高 52 收起到 0，信纸从 `translateY(-18)` 落到 0，同 260ms，`easeOutCubic`。
- 返回：反向 200ms。
- 不做信封整体放大、不做粒子、不做逐行淡入——与 M1 定下的"克制"一致。

## 10 验收标准

1. `flutter analyze` 0 issues。
2. 390×844 与 1024×1366 各出一张编辑页截图，与界面稿 05 屏对照。
3. 横线对齐用 widget test 量：取第 1 行与第 4 行文字的 `bottom` 与对应横线的 y，误差 ≤ 1px。
4. 插图：插入一张真实图片后截图，确认 -2.2° 旋转与白边留白正确。
5. 保存后 `updatedAt` 变化、正文内容读回一致（数据库断言）。
