## 1. 红线（违反即退回）

- `pubspec.yaml` 的 `hooks:` 段（sqlite3 source / url_pattern）**一个字符都不许动**。这是本机唯一能加载 sqlite3 原生库的方式。
- 一律 `import 'package:material_ui/material_ui.dart'`；禁止 `package:flutter/material.dart`（Flutter 3.50 已废弃）。
- 只用 `EnvxColors` 既有色值（`lib/ui/theme.dart`），不新增色板，不引入紫色 / 靛蓝色系。
- 开库加密一律 raw key 形式：`PRAGMA key = "x'<64位hex>'"`（32 字节密钥转 hex），禁止文本密码形式，避免 SQLCipher 二次 KDF。
- 同一时刻只允许一个执行体在工程根运行 flutter 命令。UI 线在数据层交付前**不得**运行 `pub get` / `flutter test` / `flutter analyze` / `flutter build`。
- 任何执行体不许执行 git 命令，统一由主控提交。
- 密钥只活在内存，不许写日志、不许落盘、不许进异常消息文本。

## 2. 落盘与盐（关键设计决定）

**盐不能放 meta 表**：meta 表在加密库里，读它需要密钥，而派生密钥需要盐，鸡生蛋。所以盐放库文件旁边的 sidecar：

| 项 | 规定 |
| --- | --- |
| 应用目录 | `getApplicationSupportDirectory()`（path_provider），测试用注入的临时目录 |
| 主库文件名 | `app.db` |
| 盐文件 | `app.db.salt`，16 字节二进制，权限尽量 0600 |
| 写入方式 | 先写 `app.db.salt.tmp` 再 rename 覆盖，避免半截文件 |
| 首次启动 | 无盐 → `randomSalt()` 生成并落盘；有盐 → 读 |
| 派生 | `deriveKey(password: pw, salt: salt, params: KdfParams.plan)`（`lib/core/kdf.dart`） |
| 删库 | 删 `app.db` 时同步删 `app.db.salt`（`SaltStore.reset`），否则下次用旧盐配新库 |

vault.db（M4）将来复用同一套 `SaltStore`，所以 `SaltStore` 必须以「库文件名」为参数，不能把 `app.db` 写死在类里。

## 3. 表结构（drift，两个库共用同一份定义）

字段与类型照技术方案 04 节，不得增删字段名。drift 表类用 `@DataClassName` 显式指定生成的数据类名，避免生成 `NotebookTableData` 之类。

```dart
@DataClassName('Notebook')
class NotebookTable extends Table {
  @override String get tableName => 'notebook';
  TextColumn get id => text()();
  TextColumn get name => text()();
  TextColumn get color => text().nullable()();
  IntColumn get sort => integer().withDefault(const Constant(0))();
  IntColumn get createdAt => integer().named('created_at')();
  @override Set<Column> get primaryKey => {id};
}

@DataClassName('Note')
class NoteTable extends Table {
  @override String get tableName => 'note';
  TextColumn get id => text()();
  TextColumn get notebookId => text().named('notebook_id').references(NotebookTable, #id)();
  TextColumn get title => text().nullable()();
  TextColumn get body => text().nullable()();
  IntColumn get createdAt => integer().named('created_at')();
  IntColumn get updatedAt => integer().named('updated_at')();
  IntColumn get pinned => integer().withDefault(const Constant(0))();
  @override Set<Column> get primaryKey => {id};
}

@DataClassName('Attachment')
class AttachmentTable extends Table {
  @override String get tableName => 'attachment';
  TextColumn get id => text()();
  TextColumn get noteId => text().named('note_id').references(NoteTable, #id)();
  TextColumn get path => text()();
  TextColumn get mime => text().nullable()();
  IntColumn get width => integer().nullable()();
  IntColumn get height => integer().nullable()();
  TextColumn get sha256 => text().named('sha256')();
  @override Set<Column> get primaryKey => {id};
}

@DataClassName('Meta')
class MetaTable extends Table {
  @override String get tableName => 'meta';
  TextColumn get key => text()();
  TextColumn get value => text().nullable()();
  @override Set<Column> get primaryKey => {key};
}
```

索引（迁移里建）：`note(notebook_id)`、`note(updated_at)`、`notebook(sort)`。
时间戳统一 `millisecondsSinceEpoch` 的 int。`pinned` 用 0/1。
开库时必开 `PRAGMA foreign_keys = ON`。
`schemaVersion = 1`，本里程碑不写迁移策略。

## 6. UI 线要接的缝

现在的 `lib/main.dart` 是 `home: UnlockPage()`，`unlock_page.dart` 里派生完密钥只是显示耗时。M2 改成：

1. 开锁页拿到 6 位密码后：`SaltStore(dir).loadOrCreate('app.db')` → `deriveKey` → `openEnvxDatabase(dir, key)`。
2. 成功 → 进 `HomePage`（笔记本列表）；失败抛 `WrongKeyException` → 页面内提示「密码不对」，清空输入，不崩。
3. 首次启动（无盐）等同于注册：密码即成为本库密码，直接进首页。
4. 「密码不对」的正确率验证不要靠 UI 猜，靠数据层测试。
