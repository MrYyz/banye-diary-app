## 1. 开锁页（01 开锁）

### 1.1 屏名 / 用途 / 入口

- **屏名**：开锁页（`UnlockPage`，工程已存在 `lib/ui/unlock_page.dart`，M2 按本规格校正）。
- **用途**：App 启动第一屏，输入 6 位数字密码派生密钥开库；支持指纹解锁，指纹失败回落到键盘。
- **入口**：App 冷启动 `main.dart` 的 `home`；库未打开时始终停在本页。开锁成功 → 笔记本列表页（02）；密码错误 → 页内提示「密码不对」，清空输入（M2 契约第 6 节）。

### 1.2 结构层次（从外到内）

- Scaffold（背景 EnvxColors.mist）
  - SafeArea
    - Column（横向 padding 30px，底部 padding 14px）
      - 状态栏（左：时间 9:41；右：信号 + 电池图标）
      - 信封图形区（`.lock-art`，弹性占满剩余空间，居中）
      - 品牌区（`.brand`，居中）
        - 标题「信封日记」
        - 副标题「你的心事，只寄给自己」
      - 密码圆点行（`.dots`）：6 个圆点
      - 数字键盘（`.keys`，3 列网格）
      - 底部提示（`.lock-foot`）：「指纹解锁」

### 1.3 组件解剖

**信封图形（`.lock-art` 内 SVG，168×120，整体旋转 -3°）**
- 信封矩形：x4 y4，宽 160 高 112，圆角 9，填充 paper，描边 1.6px（#D8E8E3，见 0.3）。
- 封口三角线：`(4,4) → (84,64) → (164,4)`，描边 2.2px、圆角线帽，色 #BFE3DA（→ mint100）。
- 蜡封圆：圆心 (84,64)，半径 10.5，填充 mint500；圆内一条横线 `(79,64)→(89,64)`，1.8px 白。
- 信封内底纹：x52 y86，宽 64 高 2，圆角 1，色 #E8F3EF（→ mint100）。
- 工程现状：`_EnvelopePainter` 手绘 128×82，封口线/蜡封用 mint500/mint700；M2 按上面尺寸与角度校正。

**品牌区**
- 标题：文案「信封日记」，fontSize 23，w900，letterSpacing 0.09em，色 ink，居中。
- 副标题：文案「你的心事，只寄给自己」，fontSize 12，色 ink3，居中，上边距 7，letterSpacing 0.05em。
- （工程现状标题 26 / 副标题 13，副标题文案为「你的心事，只留给自己」——与设计稿不符，见自检。）

**密码圆点（`.dots`）**
- 容器：水平居中，横向 gap 19px，上下边距 24 / 22。
- 圆点：12×12，圆形；未填：透明底 + 1.5px 描边 #CADDD6（→ ink3）；已填：填充 mint700 + 描边 mint700。
- 数量：6 位（设计稿展示 4 已填 2 未填）。

**数字键盘（`.keys`）**
- 网格：3 列，行间距 13px、列间距 20px，子项居中。
- 数字键：66×66，圆形，paper 底，1px 描边 #D8E8E3，阴影 `0 2px 0 #E4EFEB`；数字 fontSize 20，w500，色 ink，居中。
- 按键内容（4 行 × 3 列）：
  - 第 1 行：1 / 2 / 3
  - 第 2 行：4 / 5 / 6
  - 第 3 行：7 / 8 / 9
  - 第 4 行：指纹键（ghost，无底色无描边无阴影）/ 0 / 删除键（ghost）
- 指纹键图标：26×26 指纹轮廓，描边 mint700，1.5px；部分路径 opacity 0.6 / 0.45 / 0.4。
- 删除键图标：22×16 信封形叉号，描边 ink2（#5E7770），1.4px。
- ghost 键：`background: transparent; border: none; box-shadow: none`。
- （工程现状按键 74×74、字号 23，与设计稿 66×66 / 20 不符；M2 按设计稿。）

**底部提示（`.lock-foot`）**
- 文案「指纹解锁」，fontSize 12.5，w700，色 mint700，居中，上边距 18，letterSpacing 0.06em。
- 派生/开锁进行中状态：文案切为「正在打开…」（M1 现状），错误时显示「密码不对」（M2 契约第 6 节）。

### 1.4 文案原文（逐字）

- 标题：`信封日记`
- 副标题：`你的心事，只寄给自己`
- 底部：`指纹解锁`
- 进行中：`正在打开…`
- 错误提示：`密码不对`（契约规定，设计稿未画）
- 键盘数字：`1 2 3 4 5 6 7 8 9 0`

### 1.5 颜色 / 字号 / 行高

- 背景：EnvxColors.mist；标题 ink；副标题/提示辅助 ink3；主强调 mint700；蜡封 mint500；按键底 paper。
- 标题 23 / w900；副标题 12 / w400；按键数字 20 / w500；底部 12.5 / w700。
- 开锁页无正文段落，不触发 14/28 行盒规则；若后续加错误说明文字，按正文 14 + height 2.0。

### 1.6 手机 / 平板差异

- 设计稿开锁页仅手机壳。平板（1024×1366 / 900×576）M2 不做专属布局：键盘与图形在更宽屏幕上水平居中，列间距可随宽度拉伸，按键直径维持 66；M6 再做平板双栏。
- 竖屏平板上本页宽度按手机逻辑宽度（约 360）居中，两侧留 mist 底。

### 1.7 交互与动效

- 点数字键：追加一位；满 6 位自动提交（`_tap` 现状逻辑保留）。
- 按压反馈：按键按下 scale 0.94，90ms（工程 `_Pressable` 现状保留）。
- 删除键：退一位；空密码时不响应。
- 指纹：点击指纹键调起生物识别；失败自动回落到键盘（屏注：「指纹失败自动回落到键盘」）。
- 提交中：键盘禁用（`_busy`），底部文案切「正在打开…」。
- 错误：抛 `WrongKeyException` → 清空圆点、底部提示「密码不对」，不崩；提示样式见 0.3 表中橙棕条目的处置（M2 用 ink2 或 mint700 均可，不新增橙色常量）。
- 页面切换：开锁成功 → 进首页，默认平台转场；M2 不指定自定义过渡曲线。

### 1.8 边界情况

- 密码长度：固定 6 位；满 6 位后再按数字不追加。
- 首次启动（无盐）：输入即注册，直接进首页（契约第 6 节）。
- 长错误文案：底部提示单行，超长省略号截断。
- 指纹不可用：指纹键置灰不可点，仅键盘可输入。

## 3. 笔记列表页（04 笔记本内 · 信封卡片列表）

### 3.1 屏名 / 用途 / 入口

- **屏名**：笔记列表页（信封卡片列表）。
- **用途**：展示某笔记本下的全部笔记，按分组（今天 / 上周 …）排列；顶部搜索框在本笔记本内搜索；行内带信封小图标、标题、正文预览、时间/缩略图。
- **入口**：首页点普通笔记本卡片进入。

### 3.2 结构层次（从外到内）

- Scaffold（背景 EnvxColors.mist）
  - SafeArea
    - 顶部栏（`.list-hd`，两端对齐，左右 padding 20，上边距 2）
      - 返回箭头（左）
      - 标题（中，`.ttl`）：笔记本名
      - 更多图标（右，三个点）
    - 搜索框（`.search`）
    - 分组标题（`.sect`）×N
    - 笔记行（`.row`）×N
      - 信封小图标（`.ico`）
      - 中部文字组（`.mid`）：标题 + 预览
      - 右侧：时间（`.rdate`）或缩略图（`.thumb`）

### 3.3 组件解剖

**顶部栏（`.list-hd`）**
- 布局：`Row`，`AlignItems: center`，两端对齐，左右 padding 20。
- 返回箭头：18×18，左向箭头，描边 ink，1.6px，圆角线帽。
- 标题：fontSize 17，w900，letterSpacing 0.05em，ink。
- 更多图标：18×18，三个实心圆点（r1.6），ink 填充。

**搜索框（`.search`）**
- 尺寸：高 38，左右 margin 20，上边距 15；圆角 11，paper 底，1px 描边 #D8E8E3。
- 内部：`Row`，gap 9，padding 0 12，垂直居中。
- 搜索图标：15×15，圆圈 + 手柄，描边 ink3，1.5px。
- 占位文案：`搜索这个笔记本`，fontSize 12，色 ink3，letterSpacing 0.02em。
- 交互见第 4 节。

**分组标题（`.sect`）**
- 文案：`今天` / `上周`（设计稿两个分组；其余分组按时间落到 `今天` / `昨天` / `本周` / `上周` / 更早，M2 先实现今天、上周两组）。
- 字号 10.5，色 ink3，letterSpacing 0.12em；margin 19 20 6。

**笔记行（`.row`）**
- 布局：`Row`，`AlignItems: center`，gap 12，padding 11 20；底部分隔线 1px #EEF6F3（→ mint100）。
- 信封小图标（`.ico`）：36×36，固定宽高不收缩；SVG 与首页封面同构（矩形 rx3 + 封口三角 + 蜡封圆），按笔记本封面色着色。
- 中部（`.mid`）：`Expanded`，`min-width: 0`。
  - 标题（`.rt`）：fontSize 13.5，w700，letterSpacing 0.02em，ink；单行省略。
  - 预览（`.rs`）：fontSize 11，色 ink3，上边距 4，letterSpacing 0.02em；单行省略。
- 右侧时间（`.rdate`）：fontSize 10.5，色 ink3，不收缩，letterSpacing 0.02em；今天的笔记显示 `HH:MM`，更早显示 `MM/DD`。
- 右侧缩略图（`.thumb`）：44×44，圆角 8，`overflow: hidden`，1px 描边 #D8E8E3；有附件的笔记显示缩略图，替代时间位。

### 3.4 文案原文（逐字，含分组与示例笔记）

3. 标题 `关于那件小事`；预览 `其实我早就没生气了，只是不知道怎么开口`；时间 `09:24`；图标 blush

上周分组：

- 空态 / 无结果文案：设计稿未画，见 3.8 与第 4 节。

### 3.5 颜色 / 字号 / 行高

- 背景 mist；行底 paper（透明，透出 mist）；标题 ink；预览/时间/分组 ink3；图标随封面 sun/sky/blush；分隔线 mint100。
- 顶部标题 17 / w900；行标题 13.5 / w700；行预览 11 / w400；时间 10.5 / w400；分组 10.5 / w400；搜索占位 12 / w400。
- 行预览为单行省略，不触发 14/28 正文行盒；编辑页正文的 14/28 规则属 M3。

### 3.6 手机 / 平板差异

- 手机：单列纵向列表，行左右 padding 20；搜索框通栏。
- 平板横屏（06 屏）：左侧 266px 栏为笔记本列表，右侧为编辑区；笔记列表在平板上 M2 先沿用手机单列布局，宽度居中限宽（建议最大 560），左右留白 mist；双栏列表→详情联动留 M6。

### 3.7 交互与动效

- 点返回箭头 → 回首页。
- 点行 → 进编辑页（05，M3；M2 可先占位）。
- 点更多图标 → 笔记本级菜单（重命名 / 改色 / 删除）。
- 长按行 → 笔记菜单（置顶 / 删除）；置顶对应 `NoteRepo.togglePinned`，排序 pinned desc, updatedAt desc（契约第 4 节）。
- 搜索框聚焦 → 键盘弹起，列表不被遮挡：搜索框吸顶，列表区域 `resizeToAvoidBottomInset` 留出键盘高度；占位文案变光标。
- 按压反馈：行按压透明度 0.85，90ms。
- 分组吸顶：滚动时分组标题可吸顶（设计稿未明确，M2 普通滚动即可）。

### 3.8 边界情况

- **长标题**：单行省略（ellipsis），不换行。
- **长正文预览**：单行省略；预览取正文第一段前 N 字，设计稿为单行，不做多行预览。
- **无标题笔记**：标题位显示 `无标题`（契约 `title` 可空）。
- **空笔记本**：列表区居中空态——信封轮廓图标 + 文案`还没有信` + 副文案`点右下角 + 写第一封`；分组标题不显示。
- **有附件无正文**：预览位显示图片占位说明（设计稿未给文案，M2 用 `[图片]`）。
- **时间缺失**：`createdAt` 为 0 时时间位留空。
- **缩略图加载失败**：退回信封小图标，不显示碎图。

## 4. 搜索（本笔记本内 / 全局）

### 4.1 屏名 / 用途 / 入口

- **屏名**：搜索态（复用笔记列表页搜索框；契约 `NoteRepo.search` 为标题 + 正文 LIKE、忽略大小写，空串返回空表）。
- **用途**：在当前笔记本内过滤笔记；首页搜索图标进入时为全局搜索（跨笔记本）。
- **入口**：
  - 笔记列表页顶部搜索框（本笔记本内）。
  - 首页右上角搜索图标（全局，M2 可先实现本笔记本内，全局结果分组展示留 M3）。

### 4.2 结构层次

- 顶部搜索框（同 3.3 `.search`），聚焦后：
  - 右侧出现清除按钮（×，ink3，16×16；设计稿未画，按通用规则补）。
  - 下方列表切换为搜索结果列表，行结构同 3.3。
- 无结果时显示空态块（见 4.8）。

### 4.3 组件解剖

- 搜索框：尺寸/描边/圆角同 3.3。
- 输入文字：fontSize 12，色 ink（输入态），占位 ink3。
- 结果行：同笔记行；命中关键词不做高亮（M2）。
- 清除按钮：16×16，圆形浅底或纯图标，ink3。

### 4.4 文案原文

- 占位符：`搜索这个笔记本`
- 无结果空态（设计稿未画，M2 拟定）：主文案`没有找到相关的信`；副文案`换个词试试，或检查是否写错了字`。
- 全局搜索占位（首页入口，拟定）：`搜索所有信`。

### 4.5 颜色 / 字号

- 输入文字 ink；占位/图标 ink3；结果标题 ink、预览 ink3；其余同 3.5。

### 4.6 手机 / 平板差异

- 搜索框在手机通栏；平板上搜索框限宽同列表区。键盘弹起时搜索框保持可见。

### 4.7 交互与动效

- 输入即搜（debounce 建议 200ms），调 `NoteRepo.search(query)`；空串返回空表，不清空数据库。
- 点清除 → 清空关键词，恢复全量列表。
- 点返回（搜索态下）→ 先退出搜索，再按返回箭头回上一页。
- 键盘弹起：列表 `ResizeToAvoidBottomInset`；搜索框不被键盘压住。

### 4.8 边界情况

- **搜索无结果**：显示 4.4 空态；不显示分组标题。
- **超长关键词**：输入框单行，超出滚动。
- **特殊字符**：LIKE 通配符 `%` `_` 按普通字符转义（数据层负责）。
- **大小写**：忽略大小写（契约规定）。
- **空串**：返回空表，不展示全量。
